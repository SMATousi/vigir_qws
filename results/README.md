# Results

Detailed results for the `qws` v0.1 implementation. Every report is regenerated by

```bash
python scripts/generate_results.py          # full run (~4 min on this machine)
python scripts/generate_results.py --quick  # smaller settings for a fast check
```

Raw numbers are in [`raw/`](raw/). This run used full settings.

## Scope and caveats

- **No real quantum hardware was used.** Quantum paths ran on simulators: Ocean's classical sampler behind the
  QPU interface, and exact statevector QAOA. Hardware runs are roadmap Phase 3 ([spec/08](../spec/08-roadmap.md)).
- **Data is synthetic.** Votes follow the model's own generative law, which is a best case. Real datasets await
  open question Q1.
- **Timings are CPU wall-clock times** on a shared cloud container. They are indicative only, and they are not
  QPU access times.
